
# Sistema Inteligente de Atendimento

Projeto desenvolvido em **Python** para demonstrar diferentes estruturas de filas em uma central de atendimento.

## 🚀 Estruturas utilizadas

* **Fila Clássica (FIFO):** atende os clientes na ordem de chegada.
* **Fila Circular:** utiliza uma capacidade fixa e reutiliza posições disponíveis.
* **Fila de Prioridade:** atende primeiro os clientes com maior prioridade.

### Prioridades

| Valor | Tipo        |
| ----- | ----------- |
| 1     | Emergência  |
| 2     | Prioritário |
| 3     | Normal      |

## 📁 Estrutura

```text
fila-atendimento-hands-on/

```

## ▶️ Como executar

É necessário ter o **Python 3** instalado.

```bash
python main.py
```

O programa simula 20 clientes, demonstra as três estruturas de filas e disponibiliza um menu interativo.

## 🎯 Objetivo

Demonstrar na prática o funcionamento e as diferenças entre **fila FIFO, fila circular e fila de prioridade**.
